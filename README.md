# AI Research Paper Assistant

A four-week guided project to build a Python application that helps users explore academic papers, summarize content, and answer questions using document retrieval and language models.

## Project roadmap
- **Week 1:** PDF text extraction, text cleaning, and document preparation.
- **Week 2:** Text embeddings and semantic search.
- **Week 3:** Retrieval-Augmented Generation (RAG) and LLM integration.
- **Week 4:** Evaluation, improvement, and a simple user interface.

## Week 1 setup
1. Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r Week-1/requirements.txt`
3. Open `Week-1/PDF_Text_Extraction_and_Preprocessing.ipynb` in Jupyter.
4. Use a research-paper PDF that you are allowed to access and process.

## Important
- This is a learning prototype, not a tool for making academic or hiring decisions.
- Always verify summaries and answers against the original paper.
- Do not upload confidential or copyrighted documents unless you have permission.
